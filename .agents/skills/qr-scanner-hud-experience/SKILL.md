# QR Scanner HUD Experience Skill

## Features
1. Animated corner brackets on camera viewport.
2. Vertical sweeping laser line animation (`scanLaser`).
3. Instant bounce feedback modal on scan completion (<300ms).
4. Audio Web Audio API chime generator for positive/error states.
