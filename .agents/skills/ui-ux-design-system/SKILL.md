# UI/UX Design System Skill

## Tokens & Theme Rules
1. **Background**: `#070A11` (Deep Obsidian Slate)
2. **Surface Panels**: `#0F172A` with `border border-slate-800/80` and `backdrop-blur-md`
3. **Typography**: Google Font `Plus Jakarta Sans`
4. **Color Accents**:
   - Primary: `#3B82F6` (Electric Blue)
   - Present: `#10B981` (Emerald Glow)
   - Late: `#F59E0B` (Amber Glow)
   - Excused: `#8B5CF6` (Purple Glow)
